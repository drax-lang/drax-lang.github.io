Drax

A small, dynamically typed, functional language focused on integrations. One C program: build it, run a file, done.

Get started Installation GitHub 
curl -fsSL https://drax-lang.github.io/install.sh | sh

Linux, macOS and BSD. Builds from source into ~/.local/bin, never uses sudo. Read the script first if you prefer.

Functional

Immutable lists and frames, lambdas and the pipe operator |>. Tail calls run in constant memory.

Built for integrations

An HTTP server plus Os, List, Frame, String and Math in the standard library.

Packages

dmr installs dependencies from git or a local path into lib/.

Tooling

VS Code, Vim and Neovim support with a language server.

Take a look

hello.dx

```drax fun say(name) do print("Welcome, " ++ name) end say("Tom") ```

Run it

```sh $ drax hello.dx Welcome, Tom ```
